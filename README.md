# Q-Learning Agent

**Tabular Q-Learning** on a 5x5 GridWorld.

## Overview

- Epsilon-greedy exploration, GridWorld environment
- Reward history with moving average
- **Streamlit dashboard**

## Quick Start

```bash
pip install -r requirements.txt
streamlit run app.py
pytest tests/ -v
```

## Docker

```bash
docker compose up --build
```
